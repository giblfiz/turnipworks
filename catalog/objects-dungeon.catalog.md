# Dungeon gaps — the dungeon & prison type (2026-10-11)

Harry asked for "the rest of the fantasy genre type assets" on 2026-10-11. Most of what a dungeon wants already had a line (cell bars, rack, pressure plate, sliding block, coin pile, rubble pile, web cocoon); these are the gaps. Run `dun-01`, sku tier `dun`.

**Status (2026-10-11): specified; generated by `experiments/2026-10-11-types/dun/` (see its QA.md for what was accepted).** The adventure half's wall style is the kit family `cut-rock` (hewn from the living rock, no blocks, no joints): `wall-straight--cut-rock` (three versions), `wall-doorway--cut-rock`. Lines changed in `fantasy-core.catalog.md` / `expansion-environment.catalog.md` on the same day: `trap-blade` (ceiling -> a free-standing floor gantry), `trap-dart-wall` (kit edge -> a wall-mounted slab, mount 0), `skeleton-chained` and `sewer-grate` (mount 0, own sizes), `sewer-sluice-gate` (kit edge -> floor). `cage-hanging` is unchanged: the standing gibbet is its own role here.
