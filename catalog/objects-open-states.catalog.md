# Open states — two-state swap meshes (inn-02, 2026-10-02)

Each line is the OPEN state of an existing closed object (`open_of:`), generated by editing that object's own inn-01 (or later) plate so the pair matches: same wood, same ironwork, same proportions. The engine swaps the closed mesh for the open one (a two-state swap) rather than animating a hinge. Every variant of the closed object gets its own open SKU (listed in `runs/inn-02/manifest.tsv`). Open containers are EMPTY and deep: the plate is a 3/4 view looking into a clearly hollow interior, because single-image generation flattens cavities (chest pilot, 2026-10-02). Sizes grow where a lid or leaf swings out of the closed box. Open states are not placed by room recipes; they ride their closed object.
