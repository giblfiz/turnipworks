# Mansion rooms — recipes added for the castle / crypt / mansion batch (2026-10-05)

The mansion type in the Build tray (Genre → Type → Room). Eight rooms of its own plus two service rooms that are nearly all reuse. Each room type lists these recipes TOGETHER with the older NOB recipes that already cover part of it (`nob-parlor`, `nob-dining`, `nob-study`, `nob-bedchamber`, `nob-garden`, `nob-manor-grounds`, `nob-dressing-room`, `nob-silver-service`, `nob-study-desk`, `nob-music-room`): see `experiments/2026-10-05-castle-crypt-mansion/mansion/rooms.json` for the pairing, the focal piece, the wall family, the floors and the layout program of each room.

Stairs are the vertical kit's (`catalog/objects-vertical.catalog.md`, `docs/VERTICAL.md`): the entrance hall names `stair-grand` and the kit's turning pieces and dresses round them.

The garden is an outdoor room like the yard (`tav-yard` in `rooms-inn.md`): `plants` and `edge` are the slots the yard grammar reads by name.
