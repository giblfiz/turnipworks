Your verdict

Judge it at table distance: that is where the game is played. What you see up close is a note, not the verdict.

How it is done

Weld the vertices, simplify with meshoptimizer, recompute normals, unwrap, then ray-cast from the small model to the original to paint its detail into a normal map (and its colours into a texture, if it has any). The converted side shows the actual GLB file that was written, loaded back in.
