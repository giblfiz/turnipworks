# Ring tuner (2026-10-15)

The primary tuner is now the **live Ring lab** at `https://turnipworks.net/?ringlab=1`: a real table, camera and selection, with a local-only prototype ring and collapsible controls. The URL opens a reusable lab campaign with a furnished room, building, pawns, door and light. `../ring.html` remains the quick offline bench; both pages import the same `engine/client/ringlab/` geometry, renderer, panel and presets.

Each arc is independent in v2 JSON: `closed`, `primary`, `secondary`, `menu`, `conditions`, `faction`, `nested`. Every arc carries `holds`, `radius`, `start`, `span`, `fit`, `direction`, `gap`, `size`, `x`, `y`, `from`, `duration`, `stagger`, and `easing`; `tracks` and label/icon settings are siblings. Snap helpers set values once and never constrain later edits. V1 records migrate at load. The line icons always remain selectable; sets and alternates read `assets/ui-icons/manifest.json` on each load. Save writes the existing ratings `ring` record only on click; working settings stay in localStorage.

The live surface builds content from `createRegistry` and `menuFor` on each selection, so its permissions and conditional actions follow the current game. The offline snapshot `ring/registry.json` is regenerated by `ring/extract.mjs` at deploy. Built-ins are *Current game · baseline*, *Mockup 11 · close reading*, *Tight horseshoe* and *Quiet brass · Fauna*. The baseline and mockup geometry are inferences, for comparison rather than endorsement. Buttons, labels and active tracks are checked against the forbidden 3–6 o'clock sector and viewport; bad settings stay editable and show warnings.
