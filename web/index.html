True scale

How big is a turnip?

Every catalog object now carries a real-world size in inches (with an optional range: a barrel can run from about 2 ft to 10 ft). Generated meshes arrive normalized, so each one here is scaled to its catalog height and stood on a 5-ft grid.

Scaled by height, the heroic style comes out about 1.3× stouter than a realistic catalog box: that's the house style, not an error, and the placement engine should expect it.

Verdict

All four are good.

These are small props on a table in the background of play, not hero pieces. At that scale every canary object works — including the turnip pile, whose fused back side only shows up close. The close-up notes on each card are for the record, not verdicts.

Provenance: plates from text plus one accepted house-style reference; every prompt, hash and setting is recorded beside the assets.
